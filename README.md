# NOXTRON 1.0

NOXTRON 1.0 is a text-based personal assistant inspired by advanced AI systems like JARVIS. It responds to simple voice-like commands typed by the user and performs basic tasks such as telling time, opening websites, and launching applications.

## Features

- Greets the user and introduces itself
- Shows current time and date
- Opens websites (Google, YouTube, GitHub, Wikipedia)
- Launches basic apps (Notepad, Calculator on Windows)
- Provides a help menu of available commands
- Exits cleanly on command

## Technologies Used

- Python
- `webbrowser` module for opening websites
- `subprocess` module for launching applications
- `datetime` module for time and date

## How to Run

1. Open Jupyter Notebook or a Python editor.
2. Paste the NOXTRON 1.0 code into a cell or file.
3. Run the code.
4. Type commands like `hello`, `time`, `open youtube`, or `help`.
5. Type `exit` to end the session.

## Limitations

- Works with text input only (no voice yet).
- App-launching commands are designed for Windows.
- Does not use AI or machine learning; it follows predefined rules.

## Future Improvements

- Add text-to-speech so NOXTRON can speak its replies.
- Add speech recognition for voice commands.
- Support more apps, websites, and system controls.
- Make it cross-platform (Windows, macOS, Linux).
